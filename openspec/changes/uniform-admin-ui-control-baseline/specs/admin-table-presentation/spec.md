## ADDED Requirements

### Requirement: 表头与单元格内边距一致
表格的表头与单元格 MUST 使用相同的水平与垂直内边距，使列内容与列标题左边界对齐。

#### Scenario: 列标题与内容左边界对齐
- **WHEN** 渲染任一数据表格
- **THEN** 每列的表头文字与该列单元格内容的左边界重合

#### Scenario: 跨页表格内边距一致
- **WHEN** 对比不同页面中的数据表格
- **THEN** 各表格的表头与单元格使用相同的内边距取值

### Requirement: 数值列右对齐且可排序
数值型列 MUST 右对齐并使用等宽数字，使小数点与位数成列以便按位比对；可比较的数值列 MUST 支持排序。

文本型列 MUST 左对齐；操作列 MUST 与其表头的对齐方式一致。

#### Scenario: 数值列按位对齐
- **WHEN** 表格中渲染 Token 数与费用等数值列
- **THEN** 这些列右对齐且数字等宽，同列各行的小数点位置对齐

#### Scenario: 数值列可排序
- **WHEN** 用户点击数值列的表头
- **THEN** 表格按该列数值排序

#### Scenario: 操作列与表头对齐一致
- **WHEN** 渲染包含操作列的表格
- **THEN** 操作列内容的对齐方向与其表头的对齐方向相同

### Requirement: 恒定值列降级为次要信息
在真实数据下取值恒定不变的列 MUST NOT 独占表格列位，MUST 降级为行内次要信息，仅在取值偏离默认时予以视觉强调。

#### Scenario: 恒定值不再独占列
- **WHEN** 某列在全部数据行中取值相同
- **THEN** 该信息以行内次要文本呈现，表格不为其保留独立列

#### Scenario: 非默认值获得强调
- **WHEN** 某行该信息的取值偏离默认
- **THEN** 该取值以区别于次要文本的样式呈现

#### Scenario: 列数减少后不再横向滚动
- **WHEN** 在常规宽度视口下渲染表格
- **THEN** 表格内容在可视区域内完整呈现，无需横向滚动

### Requirement: 分页实现与位置统一
分页 MUST 在全站使用同一实现，MUST 置于其所属数据卡片内部，MUST NOT 出现同一产品内多套分页控件并存或分页游离于卡片之外。

#### Scenario: 分页位于卡片内
- **WHEN** 渲染任一带分页的列表页
- **THEN** 分页控件位于该列表所属的卡片内部

#### Scenario: 跨页分页外观一致
- **WHEN** 对比不同列表页的分页控件
- **THEN** 各分页的控件形态、尺寸与每页条数选择器保持一致

### Requirement: 表格结构声明与实际列数一致
表格中跨列渲染的行 MUST 使用与实际列数相符的跨列数；加载态与空态 MUST NOT 同时渲染。

#### Scenario: 展开行不溢出
- **WHEN** 展开某数据行的详情
- **THEN** 展开区域的背景边界与表格列范围一致，不溢出至列范围之外

#### Scenario: 加载态与空态互斥
- **WHEN** 展开区域的数据正在加载
- **THEN** 仅呈现加载态，不同时呈现空态内容
