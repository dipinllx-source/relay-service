## ADDED Requirements

### Requirement: 样式定义来源唯一
每个全局样式类 MUST 在整个样式体系中只有一处定义，MUST NOT 出现同名规则在多个文件或同一文件内重复定义的情况。

`.btn`、`.form-input`、`.card`、`.stat-card` 当前存在跨文件与文件内的重复定义，MUST 收敛为各自唯一的定义处。

#### Scenario: 全局类无重复定义
- **WHEN** 检索样式文件中的全局类定义
- **THEN** `.btn`、`.form-input`、`.card`、`.stat-card` 各自只出现一处定义

#### Scenario: 去重后视觉表现不变
- **WHEN** 移除重复定义段并重新构建
- **THEN** 各页面的按钮、输入框与卡片视觉表现与去重前保持一致

### Requirement: 基础控件类具备完整尺寸规格
基础控件类 MUST 自带 height、padding 与 font-size，使调用点无需自行补充内边距即可获得正确尺寸。

`.btn` MUST 提供 sm / md / lg 三档尺寸变体，各档的高度、内边距与字号均在类定义中确定。

#### Scenario: 仅用基础类即得到正确尺寸
- **WHEN** 某按钮只声明基础类与尺寸变体类，不附加任何手写内边距
- **THEN** 该按钮渲染出该档位规定的高度与内边距

#### Scenario: 尺寸档位可区分
- **WHEN** 分别使用 sm、md、lg 三档
- **THEN** 三者渲染出三种互不相同且各自固定的高度

### Requirement: 同类控件在全站使用同一规格
同一类控件 MUST 在全站范围内使用同一档高度与圆角，包括管理页与对外展示页；同一行内并排的控件 MUST 具有相同高度并对齐于同一基线。

按钮、输入框、下拉与分段器归为一档；行内小按钮归为另一档；卡片使用统一的圆角与内边距。

#### Scenario: 同行控件高度一致
- **WHEN** 任意页面的工具条中并排渲染筛选下拉、输入框与按钮
- **THEN** 这些控件的渲染高度相同且垂直居中对齐

#### Scenario: 对外展示页与管理页规格一致
- **WHEN** 对比对外展示页与管理页的同类控件
- **THEN** 两者使用相同的高度与圆角取值

#### Scenario: 卡片规格统一
- **WHEN** 对比不同页面中的内容卡片
- **THEN** 各卡片使用相同的圆角取值与内边距区间

### Requirement: 开关控件收敛为单一实现
开关控件 MUST 使用单一尺寸、单一选中色与单一实现方式，MUST NOT 在不同位置采用不同尺寸或自行手写等价控件。

#### Scenario: 开关尺寸与配色一致
- **WHEN** 浏览设置页中的全部开关
- **THEN** 所有开关渲染出相同尺寸，且选中态使用同一主色

#### Scenario: 不存在手写替代实现
- **WHEN** 检索模板中的开关控件
- **THEN** 不存在以按钮元素手写模拟开关的实现

### Requirement: 容器布局不得改变控件固有高度
控件 MUST NOT 因父容器的对齐方式而被拉伸或压缩至其规格之外的高度；弹性容器中并排的操作区 MUST 显式指定居中对齐。

控件内的图标与文字 MUST 保持在同一行，MUST NOT 因宽度不足而折行导致控件高度成倍增加。

#### Scenario: 操作按钮不被容器拉伸
- **WHEN** 页面工具区左侧为多行筛选器、右侧为操作按钮组
- **THEN** 右侧按钮保持其规格高度，不被拉伸至与左侧等高

#### Scenario: 按钮文字不折行
- **WHEN** 工具栏中并排渲染多个带图标的按钮
- **THEN** 每个按钮的图标与文字位于同一行，按钮高度为单行高度

### Requirement: 尺寸约束不得自相矛盾
同一元素的宽度或高度约束 MUST 保持自洽；表头与其对应单元格的宽度约束 MUST NOT 相互冲突。

#### Scenario: 表头与单元格宽度约束一致
- **WHEN** 检查任一表格列的表头与单元格宽度约束
- **THEN** 两者的最小宽度与最大宽度取值不产生冲突
- **AND** 该列内容按预期宽度渲染而非被拉满或压缩

### Requirement: 可交互控件必须产生实际效果
呈现为可交互的控件 MUST 影响系统行为；不产生任何效果的控件 MUST NOT 呈现给使用者。

登录页的「记住我」勾选框未参与任何请求与会话逻辑，MUST 移除或实现其语义。

#### Scenario: 登录页不呈现无效控件
- **WHEN** 用户打开登录页
- **THEN** 页面不呈现不影响任何行为的勾选项

#### Scenario: 保留的控件均可验证生效
- **WHEN** 操作页面上任一开关或勾选项
- **THEN** 该操作对应的系统行为发生可观察的变化
