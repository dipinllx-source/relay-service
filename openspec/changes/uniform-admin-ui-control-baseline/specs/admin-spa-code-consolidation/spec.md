## ADDED Requirements

### Requirement: 仓库不保留无引用的前端文件
无路由且无任何引用的视图、零引用的组件、仅存于注释中的组件 MUST 从仓库中移除；随之失效的专属接口函数 MUST 一并移除。

#### Scenario: 无引用视图被移除
- **WHEN** 某视图既未在路由中注册，也未被任何组件引用
- **THEN** 该视图文件不再存在于仓库中

#### Scenario: 专属接口函数随之移除
- **WHEN** 某组接口函数的唯一消费方已被移除
- **THEN** 这些接口函数不再保留

#### Scenario: 移除后构建与页面均正常
- **WHEN** 移除无引用文件后重新构建
- **THEN** 构建成功且各页面功能不受影响

### Requirement: 组件内不保留无调用点的分支与遗留代码
组件中无任何调用点的模式分支 MUST 移除；被注释掉的函数、遗留的调试输出与静态占位内容 MUST NOT 保留在仓库中。

#### Scenario: 无调用点分支被移除
- **WHEN** 某组件的某个模式分支在全仓无任何调用
- **THEN** 该分支的模板与样式一并移除

#### Scenario: 不保留调试输出与占位
- **WHEN** 检索页面与组件代码
- **THEN** 不存在遗留的调试输出语句，也不存在声明为待接入的静态图表占位

### Requirement: 同构页面收敛为共用组件
结构高度一致、仅在少数维度上存在差异的页面 MUST 抽取为共用组件，差异通过参数传入，MUST NOT 以复制实现的方式并存。

两个使用记录页结构几乎完全一致，MUST 收敛为同一表格组件，实体标签、取数方式与筛选维度作为参数传入。

#### Scenario: 记录页共用同一组件
- **WHEN** 分别打开按 API Key 与按账户维度的使用记录页
- **THEN** 两页由同一组件渲染，仅实体标签与筛选维度不同

#### Scenario: 两页行为保持一致
- **WHEN** 在两个记录页分别执行筛选、排序、分页与导出
- **THEN** 两页的交互行为与呈现规则一致

#### Scenario: 可选列按需呈现
- **WHEN** 某维度需要额外列而另一维度不需要
- **THEN** 该列通过参数控制是否呈现，不需要复制整个页面实现

### Requirement: 重复布局与重复卡片实现收敛
在多个页面间重复的导航与页脚布局 MUST 抽取为共用布局组件；重复实现的统计卡 MUST 收敛为单一实现并被各页面复用。

#### Scenario: 对外页共用导航与页脚
- **WHEN** 浏览各对外展示页
- **THEN** 其导航与页脚由同一共用布局渲染

#### Scenario: 统计卡实现唯一
- **WHEN** 检索呈现统计指标的卡片实现
- **THEN** 全站使用同一套卡片实现，不存在多份等价的手写实现

#### Scenario: 收敛后视觉与交互一致
- **WHEN** 对比收敛前后各页面的导航、页脚与统计卡
- **THEN** 其视觉与交互保持一致或按统一基线改进，不出现页面间差异
