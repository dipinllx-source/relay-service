## ADDED Requirements

### Requirement: 暗色模式覆盖完整
参与暗色模式的页面与组件 MUST 为其背景、文字与边框提供暗色变体；MUST NOT 出现外层容器已适配暗色而内部组件仍为亮色的混色情况。

#### Scenario: 内外层暗色一致
- **WHEN** 在暗色模式下打开用户面板
- **THEN** 外层容器与内部卡片均为暗色，不出现白色卡片压在深色背景上

#### Scenario: 登录页适配暗色
- **WHEN** 在暗色模式下打开登录页
- **THEN** 该页背景、输入框与按钮均呈现暗色变体

#### Scenario: 嵌套内容区不硬编码底色
- **WHEN** 在暗色模式下浏览含嵌套演示区的教程页
- **THEN** 嵌套区域底色随主题变化，不与内部组件的暗色样式冲突

### Requirement: 主题入口唯一
主题相关的控件 MUST 收敛为单一入口；配色方案选择与明暗模式切换 MUST 同时保留其能力，但 MUST NOT 各自占据独立的顶栏控件位。

#### Scenario: 顶栏仅一个主题入口
- **WHEN** 用户查看任一管理页顶栏
- **THEN** 主题相关控件只有一个入口

#### Scenario: 两项能力均可用
- **WHEN** 用户展开主题入口
- **THEN** 既可选择配色方案，也可切换明暗模式

#### Scenario: 主题入口与相邻控件规格一致
- **WHEN** 对比主题入口与顶栏其他控件
- **THEN** 两者高度与圆角一致并对齐于同一基线

### Requirement: 主题初始化仅执行一处
主题初始化 MUST 只在应用根层执行一次，各页面 MUST NOT 重复调用。

#### Scenario: 页面不重复初始化主题
- **WHEN** 检索各页面的初始化逻辑
- **THEN** 除应用根层外，各页面均不再调用主题初始化

#### Scenario: 去重后主题仍正确应用
- **WHEN** 移除重复调用后打开任一页面
- **THEN** 当前主题与配色方案被正确应用
