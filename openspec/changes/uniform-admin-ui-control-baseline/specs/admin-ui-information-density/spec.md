## ADDED Requirements

### Requirement: 无数据的区块不占据版面
在当前部署条件下恒无有效数据的区块 MUST NOT 渲染，MUST NOT 以零值或空态占据版面。

账户余额区块在仅有订阅制账户的部署中恒为零值，MUST 仅在存在具备余额语义的账户时渲染。

#### Scenario: 无余额语义账户时不渲染余额区块
- **WHEN** 部署中不存在具备余额语义的账户
- **THEN** 看板不渲染账户余额与低余额账户区块

#### Scenario: 存在余额语义账户时正常渲染
- **WHEN** 部署中存在具备余额语义的账户
- **THEN** 看板渲染余额区块并显示其真实余额与低余额情况

#### Scenario: 空态不以整卡形式占位
- **WHEN** 某列表型区块当前无条目
- **THEN** 该区块不以一整张卡片仅承载一句空态文案的形式呈现

### Requirement: 同屏不得并列口径矛盾的同名指标
同一屏内 MUST NOT 并列展示名称相同而计算口径不同的指标；若必须同时呈现，MUST 在标签上区分其口径。

#### Scenario: 总成本口径唯一
- **WHEN** 看板同屏呈现累计费用类指标
- **THEN** 该指标仅出现一次，或各处标签明确区分其统计口径

### Requirement: 可推导指标不独占版面
可由同屏其他指标直接推导得出的指标 MUST NOT 独占卡片，MUST 并入摘要区呈现。

#### Scenario: 均值类指标并入摘要
- **WHEN** 页面已呈现总量与次数两个指标
- **THEN** 由两者相除得出的均值不单独占用一张卡片

#### Scenario: 二级指标压缩为摘要行
- **WHEN** 页面存在多个非一级的累计类指标
- **THEN** 这些指标以单行摘要形式呈现而非各占一张卡片

### Requirement: 冗余与重复文案并入主结构
与同屏已高亮控件表达相同信息的说明文案 MUST NOT 重复呈现；仅承载计数或范围说明的元信息 MUST NOT 独占整行，MUST 并入所属标题行。

#### Scenario: 分组说明不与高亮控件重复
- **WHEN** 页面已通过高亮的分组切换控件表明当前分组
- **THEN** 不再以额外文案重复陈述当前分组

#### Scenario: 计数元信息并入标题
- **WHEN** 区块需要说明条目总数或展示范围
- **THEN** 该说明呈现于区块标题行内，不独占一行

### Requirement: 页面标题与工具条同行呈现
区块标题与其操作工具条 MUST 呈现于同一行的两端，MUST NOT 各自独占一行造成垂直空间浪费。

#### Scenario: 标题与工具条同行
- **WHEN** 渲染带筛选或操作控件的内容区块
- **THEN** 标题位于该行左端、控件位于同行右端
